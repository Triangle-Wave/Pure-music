# 更新日志

从 **2.0.0** 起。每个版本默认折叠，点版本号展开。最新：**2.3.13**。

完整发布页：[GitHub](https://github.com/Triangle-Wave/Pure-music/releases) · [Gitee 镜像](https://gitee.com/qingyueyin/Pure-music)（同步常滞后）

<details>
<summary><strong>2.3.13</strong></summary>

**音质标记**

- 音乐列表、播放队列与统计页歌曲排行显示 Hi-Res 与 DSD 徽章。
- Hi-Res 判定：采样率高于 44.1 kHz，或 44.1 kHz 且位深不低于 24 bit。
- DSD 曲目同时显示 DSD 与 Hi-Res 徽章；SACD 虚拟轨、DSF/DFF、DSD 采样率与 DSD 源文件都能识别。

**曲库与音质信息**

- 曲目位深进入曲库索引与列表，24bit/44.1kHz 这类边缘 Hi-Res 不再漏标。
- 索引升级后首次启动会重新读取一次标签以补齐位深，期间界面可正常使用。
- DSF 位深按 DSD 原生 1 bit 记录，详情页与列表保持一致。

**歌词**

- 修复部分歌曲第一句缺少罗马音的问题；罗马音与歌词行数一致时按行序对齐，行数不一致时按时间戳匹配并容忍首句偏移。

</details>

<details>
<summary><strong>2.3.12</strong></summary>

**TAK 播放**

- 接入 TAK 官方解码库（64 位 `bass_tak` 插件），旧版编码的 TAK 可以正常播放；这类文件此前因 FFmpeg 未实现对应解码而报“格式不支持”。
- 插件随应用分发，启动时由 BASS 自动加载，覆盖 CUE 整轨中的 TAK 曲目与直接播放。

**曲库与显示（沿用 2.3.11）**

- 整轨 TAK 不再出现在曲库、文件夹页与搜索结果中，只保留 CUE 展开的分轨。

**播放诊断（沿用 2.3.11）**

- BASS 创建流失败时记录文件名、扩展名、文件大小、错误码与可读文本。

**更新流程（沿用 2.3.11）**

- 安装助手启动过程逐步写入 `updates\installer_update.log`；助手未真正启动时应用不退出，提示手动运行安装包并给出完整路径。

</details>

<details>
<summary><strong>2.3.11</strong></summary>

**曲库与显示**
- 整轨 TAK 不出现在曲库、文件夹页和搜索结果中，只保留 CUE 展开的分轨；过滤覆盖索引加载、文件夹构造与最终聚合三处。
- 搜索匹配专辑名与艺术家，支持首字母与完整拼音，标题命中优先。

**播放诊断**
- BASS 创建流失败时记录文件名、扩展名、文件大小、错误码与可读文本（格式不支持、缺解码器等），并修正诊断日志把结构化字段一并脱敏掉的问题。

**更新流程**
- 安装助手启动过程逐步写入 `updates\installer_update.log`：助手源路径、复制结果、完整命令行、进程 PID、退出调用与异常堆栈。
- 启动助手后确认其日志已生成才退出应用；未生成时保持应用运行，提示手动运行已下载的安装包并给出完整路径。
- 启动失败保留脚本与日志，不再删除现场。

</details>

<details>
<summary><strong>2.3.10</strong></summary>

本版本与 2.3.9 内容完全一致，仅版本号递增，用于让已安装 2.3.9 的客户端能收到在线更新。

**播放与曲库**
- TTA 曲目进度条零点改用 BASS 实际定位落点，起点不再偏移
- CUE 段尾偏移按距末尾距离设置，播放止于轨尾
- 增量扫描发现 CUE 目录仍有被引用的源文件整轨条目时强制重建；曲库加载时剔除被虚拟轨覆盖的源文件条目
- CUE 最后一轨时长：内置读取器 → Windows 媒体属性 → TAK 容器头（`tBaK` + STREAMINFO）→ TTA1 头依次兜底，同一文件只探测一次
- CUE 虚拟轨封面按通用名 → 源文件同名图 → Jacket/Scans 子目录 → 内嵌图查找，支持 BMP，同目录共享一次扫描
- 搜索匹配专辑名与艺术家，支持首字母与完整拼音，标题命中优先

**歌词**
- 主来源保留逐字时间轴，其他来源按时间戳补齐翻译与罗马音，已有内容不覆盖

**音频输出**
- 共享与独占模式分别记录输出设备
- 设备名二次解析，去掉模糊匹配，失效设备不再静默切换
- 设备热插拔后自动刷新列表

**更新**
- 下载线路：自动（GitHub 直连 → Gitee 镜像 → 加速代理）、仅 GitHub、仅 Gitee、仅加速代理
- 更新清单只从 GitHub 或 Gitee 获取，加速代理只承担安装包传输
- 每条线路下载后校验 SHA256，失败自动切换下一条，全部失败时优先展示直连原因

**远程曲库**
- 新增 Navidrome、WebDAV 远程曲库
- 远程曲目参与播放统计与播放记录

**其他**
- 退出时释放音量控制
- 在线歌词请求支持取消

</details>

<details>
<summary><strong>2.3.8</strong></summary>

**播放与格式**

- 新增 TAK 原生解码，CUE 整轨中的 TAK 曲目可直接播放
- SACD ISO 支持 2CH/MCH、DST 压缩与裸 DSD，提取为 DSF 后默认直解
- PCM 缓存可选 44.1k / 88.2k / 96k / 192k 与 16/24bit；默认推荐 DSF 直解，不生成 WAV
- 修复部分格式因异步文件标志导致的“格式不支持”

**在线信息**

- 专辑、艺术家信息支持网易 / QQ / 酷狗与 MusicBrainz / Cover Art Archive
- 支持候选来源选择与“不使用/空白”，结果长期缓存
- 艺术家头像、专辑封面使用磁盘缓存，缓存目录可单独指定
- GitHub API 限流时从发布页解析版本，更新检查不再误报网络异常

**歌词**

- 在线歌词候选与来源选择，支持 QQ / 酷狗 / 网易 / AMLL
- 酷狗 KRC 缓存歌词恢复自带罗马音
- 纯假名日文行自动生成罗马音，含汉字行保持原文

**界面与性能**

- 专辑 / 歌手详情页按可用宽度重新分配头部空间，窄窗口标题与操作区不再被挤压
- 专辑卡片标题按对比度选色，补充艺术家名
- 音量拖动期间不写盘、不整页重建，松手后合并保存
- 封面、头像、在线信息使用磁盘缓存，减少重复请求

**设置与数据**

- 缓存目录可单独指定到其他磁盘，清理缓存保留已提取的 DSF
- 统一代理：所有请求走配置的代理，由代理软件自行分流
- 安装版支持应用内下载更新：校验 SHA256 后自动拉起安装向导

**修复**

- 修复 CUE/TAK 曲目播放失败
- 修复酷狗 KRC 缓存歌词缺少罗马音
- 修复专辑 / 歌手页头部布局、专辑卡片标题不可见
- 修复 GitHub 403 时更新检查显示网络异常
- 修复封面 BMP 解码失败与部分标签读取异常

</details>
