# 更新日志

从 **2.0.0** 起。每个版本默认折叠，点版本号展开。最新：**2.3.22**。

完整发布页：[GitHub](https://github.com/Triangle-Wave/Pure-music/releases)（未配置 Gitee 镜像）

<details>
<summary><strong>2.3.22</strong></summary>

**播放页与渲染**

- 歌词区、进度区、信息区与背景各自独立重绘，整页动画按区域触发刷新。
- 播放页展开时卸载库页渲染，画面仅保留单层叠绘。

**内存与资源**

- 播放中内存按 180、240、280 MB 分档收紧阈值并换出工作集。
- 切歌后归还脱离混音器的音频源，后台回声日志默认关闭。
- 封面缓存条目上限 96，切歌后清理缓存池。

**封面与歌词**

- 封面按控件物理像素尺寸解码。
- 滚动期间的封面延迟加载放宽重试。
- 切歌跳过重复歌词扫描，解屏蔽与元数据排版去重。

**窗口与频谱**

- 窗口失焦或被遮挡时动画、频谱与进度暂停，回到前台恢复。
- 窗口可见性与失焦门闩分离，闲时计时仅在窗口可见时启动，可见失焦按 30 秒进入闲时档。
- 频谱流复用，逐柱幅值以查表取得，订阅恢复前重置状态。

</details>

<details>
<summary><strong>2.3.21</strong></summary>

**专辑图片**

- 专辑详情页展示封面、封底、碟片、内页等多图，缩略图条循环切换全部候选。
- 点击主图进入全屏查看器，支持缩放、拖拽、左右切换与键盘方向键。
- 文件夹图识别 cover/front、back/rear、disc/tray、booklet/scans 等命名。
- 内嵌图读取 FLAC、MP3、M4A、DSF、DFF 中的全部图片与角色。
- 在线 Cover Art Archive 提供封底、碟片与内页，国内源命中后后台补充。
- 主图按 600×600 读取，查看器按屏幕分辨率取 2048 以内。

**行为**

- 主图优先封面；无封面时取列表第一张。
- 同角色多来源按文件夹图、内嵌图、在线图取一张；内页与其他保留多张。
- 显式选择在线候选时，在线封面替换本地封面；其余角色仍按来源优先级合并。

</details>

<details>
<summary><strong>2.3.20</strong></summary>

**播放队列**

- 点歌时替换当前播放项，队列其余内容与顺序保持不变。
- 随机播放模式不再因为点歌而打乱整个队列。
- 点的歌曲已在队列中时，替换当前项并移除原位置，不会出现重复。
- 队列为空时点歌只播放该曲目。
- 播放全部、多选播放与演唱会开场继续载入整份列表。

</details>

<details>
<summary><strong>2.3.19</strong></summary>

**导航**

- 详情页之间跳转时替换当前页，连续切换歌手、专辑、歌曲详情不再层层叠加。
- 从详情页返回直接回到进入详情页之前的位置。
- 从列表页、播放页首次进入详情页仍可返回原页面。

</details>

<details>
<summary><strong>2.3.18</strong></summary>

**播放页**

- 修复歌手、专辑按钮跳转后页面空白的问题，改为与「更多」菜单一致的跳转方式。

**歌手关联**

- 修复关联歌手对话框中「显示名称」输入框的浮动标签与副标题重叠的问题。
- 标题、副标题与输入框之间留出间距，输入框有内容时不再压住上方文字。

</details>

<details>
<summary><strong>2.3.17</strong></summary>

**播放页**

- 右下角提供歌手与专辑入口，直接跳转当前曲目的歌手页与专辑页。
- 多歌手曲目点击歌手按钮弹出菜单，选择要查看的歌手。
- 大窗口下播放控件与右侧工具组保持足够间距，避免窗口变窄时相互遮挡。

**歌手关联**

- 歌手详情页可把不同写法的名字关联到同一歌手，关联后作品合并显示。
- 歌手显示名称可编辑，成员可移除，关联可整体解除。
- 搜索兼容关联前的原始名字。
- 合并结果同步用于在线歌手信息与封面匹配。

**标签编辑**

- 单个音频文件的标签修改写入文件本身，写入前创建临时副本并回读校验，失败时原文件保持不变。
- 写完标签后刷新曲库索引，重启应用不再显示旧标签。
- CUE 整轨与 SACD ISO 的标签修改保存在应用内覆盖层，不修改 `.cue` 与 ISO 文件。
- 整轨覆盖层支持流派、年份、轨号总数、碟号总数、作曲、作词、厂牌、备注、BPM、语言、版权与许可。

</details>

<details>
<summary><strong>2.3.16</strong></summary>

**播放与性能**

- 播放页装饰动画跟随屏幕刷新率，不再固定 30/60fps；高刷新率屏幕下进度条、封面旋转、波浪、逐字高亮、频谱与流光更顺滑。
- 最小化或窗口不可见时动画与定时器仍会停止，恢复后歌词与动画基准重新对齐。

**曲库**

- 归档远程曲库：移除侧边栏远程入口、远程页面与相关设置；本地曲库、CUE、SACD 与 TAK 不受影响。

</details>

<details>
<summary><strong>2.3.15</strong></summary>

**播放与性能**

- 窗口不可见时换出工作集并停止定时器，降低后台内存占用。
- 播放页装饰动画降到 30fps，减少不必要的绘制。
- 窗口真正可见后再恢复绘制和动画，最小化与托盘恢复更平滑。
- 流光背景先绘制小图再放大，并复用颜色矩阵。

**歌词**

- 元数据行单独标记与绘制，不再参与正文滚动。
- 歌词尺寸未就绪时跳过滚动，避免跳动。
- LRC 导出与写回按设置保留元数据行。

**曲库与界面**

- 曲库未对齐时不缓存空歌单。
- 封面搜索记住图片尺寸。
- 封面与专辑色释放后不再写回进行中的请求。
- 波浪进度条设置在播放中切换立即生效。

**构建**

- 安装包与可执行文件的版本信息跟随发布版本更新。

</details>

**更新流程**

- 修复 GitHub API 限流时更新弹窗不显示更新说明的问题，改用更新清单中的完整日志。

**安装提示**

</details>

<details>
<summary><strong>2.3.9</strong></summary>

**播放与曲库**
- TTA 曲目进度条零点改用 BASS 实际定位落点，起点不再偏移
- CUE 段尾偏移按距末尾距离设置，播放止于轨尾
- 增量扫描发现 CUE 目录仍有被引用的源文件整轨条目时强制重建；曲库加载时剔除被虚拟轨覆盖的源文件条目
- CUE 最后一轨时长：内置读取器按 Windows 媒体属性 → TAK 容器头（`tBaK` + STREAMINFO）→ TTA1 头依次兜底，同一文件只探测一次；全部探测失败时保持原行为并记录原因
- CUE 虚拟轨封面按通用名（cover/folder/front）→ 源文件同名图 → Jacket/Scans 子目录 → 内嵌图依次查找，支持 BMP，同目录共享一次扫描
- 搜索：音乐结果匹配专辑名与艺术家，支持首字母与完整拼音，标题命中优先

**歌词**
- 跨来源合并：主来源保留逐字时间轴，其他来源按时间戳补齐缺失的翻译与罗马音，已有内容不覆盖

**音频输出**
- 共享模式与独占模式分别记录输出设备
- 设备名支持二次解析并去掉模糊匹配，失效设备不再静默切换
- 设备热插拔后自动刷新列表

**更新**
- 下载线路：自动（GitHub 直连 → Gitee 镜像 → 加速代理）、仅 GitHub、仅 Gitee、仅加速代理
- 更新清单只从 GitHub 或 Gitee 获取，加速代理只承担安装包传输
- 每条线路下载后校验 SHA256，校验不通过自动切换下一条线路，全部失败时优先展示直连原因

**远程曲库**
- 新增 Navidrome、WebDAV 远程曲库
- 远程曲目参与播放统计与播放记录

**上游同步**
- 合并上游的输出设备、歌词请求、滤镜与背景渲染、界面提示等修复

**其他**
- 退出时释放音量控制
- 在线歌词请求支持取消

</details>

<details>
<summary><strong>2.3.8</strong></summary>

**播放与格式**

- 新增 TAK 原生解码，CUE 整轨中的 TAK 曲目可直接播放
- SACD ISO 支持 2CH/MCH、DST 压缩与裸 DSD，提取为 DSF 后默认直解
- PCM 缓存可选 44.1k / 88.2k / 96k / 192k 与 16/24bit；默认推荐 DSF 直解，不生成 WAV
- 修复部分格式因异步文件标志导致的“格式不支持”

**在线信息**

- 专辑、艺术家信息支持网易 / QQ / 酷狗与 MusicBrainz / Cover Art Archive
- 支持候选来源选择与“不使用/空白”，结果长期缓存
- 艺术家头像、专辑封面使用磁盘缓存，缓存目录可单独指定
- GitHub API 限流时从发布页解析版本，更新检查不再误报网络异常

**歌词**

- 在线歌词候选与来源选择，支持 QQ / 酷狗 / 网易 / AMLL
- 酷狗 KRC 缓存歌词恢复自带罗马音
- 纯假名日文行自动生成罗马音，含汉字行保持原文

**界面与性能**

- 专辑 / 歌手详情页按可用宽度重新分配头部空间，窄窗口标题与操作区不再被挤压
- 专辑卡片标题按对比度选色，补充艺术家名
- 音量拖动期间不写盘、不整页重建，松手后合并保存
- 封面、头像、在线信息使用磁盘缓存，减少重复请求

**设置与数据**

- 缓存目录可单独指定到其他磁盘，清理缓存保留已提取的 DSF
- 统一代理：所有请求走配置的代理，由代理软件自行分流
- 安装版支持应用内下载更新：校验 SHA256 后自动拉起安装向导

**修复**

- 修复 CUE/TAK 曲目播放失败
- 修复酷狗 KRC 缓存歌词缺少罗马音
- 修复专辑 / 歌手页头部布局、专辑卡片标题不可见
- 修复 GitHub 403 时更新检查显示网络异常
- 修复封面 BMP 解码失败与部分标签读取异常

</details>
